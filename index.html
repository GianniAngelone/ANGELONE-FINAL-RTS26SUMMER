Hardware Security – Interrupt & Bottom-Half System

Theme: Tamper detection. A button acts as a security sensor.

When the button is pressed, a fast interrupt (top-half) runs. It quickly signals two bottom-half tasks. Those tasks measure the wake-up latency and log the tamper event.

System Architecture

GPIO 18 (Tamper Button)
         |
         v
   button_isr (top-half / interrupt)
         |                 |
    semaphore          notification
         |                 |
         v                 v
  btn_sem task       btn_notif task
  (priority 12)      (priority 12)

Task Table

Task Priority Role
btn_sem 12 Bottom-half using binary semaphore
btn_notif 12 Bottom-half using direct notification
load_a (optional) 15 Background load – can delay bottom-half
load_b 10 Background load
load_c 5 Background load
load_d 2 Background load

Key Latency Results

  • Idle – Notification: max ≈ 30 µs
  • Idle – Semaphore: max ≈ 2300 µs
  • Under load both paths get slower because Task A (priority 15) can preempt the bottom-half tasks.

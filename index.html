Hardware Security – Interrupt & Bottom-Half System

Theme: Tamper detection using a button as a security sensor.

When the button (tamper sensor) is pressed, a fast interrupt runs. The interrupt quickly signals two bottom-half tasks. Those tasks measure how long it took to wake up and log the event.

System Architecture

GPIO 18 (Tamper Button)
        |
        v
   button_isr  (top-half)
        |           |
   semaphore     notification
        |           |
        v           v
  btn_sem task   btn_notif task
  (priority 12)  (priority 12)

Task Table

TaskPriorityRole
btn_sem12Bottom-half (semaphore path)
btn_notif12Bottom-half (notification path)
load_a (when enabled)15Background load
load_b10Background load
load_c5Background load
load_d2Background load

Key Results

  • Idle Notification max latency: ~30 µs
  • Idle Semaphore max latency: ~2300 µs
  • Under load both paths get slower (Task A at priority 15 causes the delay)
